# 多向决策矩阵（Decision Matrix）

把分散在对话历史、公开笔记队列、在途工程与个人生活约束中的信息收拢成**一张全盘对齐、可直接拍板执行的多向决策矩阵**。本技能是跨赛道统筹视图，不替代各单项执行技能，不凭猜测补全未核验事实，也不代用户对外发声或做不可逆承诺。

## 触发说法

- `决策矩阵` / `汇报整体决策矩阵` / `全局决策矩阵`
- `多向优先级` / `全局优先级排序`
- `决策矩阵：<聚焦主题>`（仍须展示全盘各向约束，只将细表篇幅向聚焦赛道倾斜）

## 五条校准纪律（执行前必过）

1. **反近因偏差（Full-Board Anti-Omission）**：绝不只盯着最近 1–2 轮新聊到的事务排序。动笔前必须通盘核对每一条仍在运行的赛道（全部梯队的外部机会与现职基线、主项目的全部演进支柱、存量内容与素材转化队列、学习与基本功练习队列、个人精力配额），明确标注保留、升级、降级、设置死线或止损的理由，不能静默遗漏在途项。
2. **证据分层与克制表达（Evidence Tiering）**：严格区分 `[已核验事实]`、`[口头/待验信号]` 与 `[助手建议]`。不把口头赞赏写成书面条件，不把局部代理指标当成端到端收益，也不用浮夸修辞、鸡汤鼓励或自言自语式反问句填充篇幅。
3. **五向耦合固定骨架（5-Track Coupled Matrix）**：固定覆盖以下五个耦合维度（按当前问题权重微调排序，不可缺项）：
   - **① 职业与机会博弈**：在职基线与撤离边界 vs 全量外部机会分档、核心筹码与验真死线；
   - **② 核心项目与技术演进**：架构主线、评测与验证轨、核心能力与生态协同，明确人机分工边界；
   - **③ 内容转化与社区运营**：存量素材去碎片化收敛、高杠杆传播波次与社区反馈闭环；
   - **④ 学习补齐与基本功队列**：紧贴核心短板的高 ROI 一手精读与闭卷硬技能训练；
   - **⑤ 个人带宽配额与硬红线**：真实可支配工时预算、身心负荷预警与不可逾越的边界清单。
4. **工时现实与人机分工（Human-Only vs Agent-Delegated）**：所有建议必须落进用户真实可用的时间窗口，明确区分 **Human-Only**（必须本人面试、谈判、精读判断、真机体验验收、最终拍板与点击发布）与 **Agent-Delegated**（代码清理、回归测试、草稿整理、检索对账），禁止给本人安排低杠杆手写流水线任务。
5. **私有上下文就地对账（Optional Local Overlay）**：若当前工作区 `.local/AGENTS.md` 配置了私有决策目录、持久化规则与只读快照脚本，先静默完成本轮新确认事实的增量落盘并运行只读快照对账，再输出矩阵；公开仓库本身不存放任何私有路径、身份或内部详情。

## 输出结构模板

1. **一、总纲裁决（3–5 句直给核心）**：点透当前阶段的第一性约束、最大复利杠杆与唯一不能输的胜负手。
2. **二、五向耦合主决策矩阵（Markdown 表格）**：
   列头固定为：`方向 | 当前锚点与状态（事实 vs 待验） | 跨线杠杆（与他向如何互相放大） | 最大风险 / 盲区 | 本人必做（含硬死线） | Agent / 外部委派`
3. **三、关键子矩阵（按需展开 `1–2` 张，如「机会全量分档博弈表」「近期内容转化波次表」）**：防止高层抽象吞掉具体梯队与死线。
4. **四、跨方向“一石多鸟”高杠杆清单（`≤ 4` 条）**：说明哪几件低耗时动作能同时推进 ≥ 2 个方向（例如一次真实技术复盘同时服务核心项目演进、外部高管深聊与社区高赞帖）。
5. **五、近期时间窗最小闭环（如本周末 / 本周可执行动作）与明确不做清单（Stop List & 红线）**：列出当前明确 `0h` 投入的降噪项与安全/合规/隐私红线。

## 检查与边界

- 输出给用户的方案优先用平实凝练的中文，附可点击 `file://` 本地落点或原始一手链接。
- 涉及公开/私有协同仓库时，输出报告本身或顺带产生的公开文件不得混入私有对话、公司内部细节或未审查草稿。
- 若用户在本轮披露了新的事实更新，先按工作区约定完成历史保留式增量更新，再基于更新后全盘状态生成决策矩阵，不在文末反问“是否需要记录”。
