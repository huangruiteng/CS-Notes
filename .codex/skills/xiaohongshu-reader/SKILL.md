# 小红书阅读

从用户提供的分享链接进入，使用当前可用网页读取或已授权浏览器工具。分享参数可能是临时访问凭证：仅在读取所需范围内使用，公开引用保留稳定页面地址，不发布原始参数或登录信息。

- 核对帖子身份、作者、日期、标题和正文。短链接需读到最终帖子，不能据跳转页推断内容。
- 正文只有话题标签或短 caption 时，查看图片页并按真实顺序阅读。无法查看图片则明确正文未读全，不用标签编造摘要。
- 图中机制、表格或公式给出解释，区分发布者的观点与可核验事实；涉及技术、产品或近期事件时追一手来源。
- 只读取用户所需范围。评论只有在任务需要时才读；不顺便收集用户个人页、关注、点赞或评论。
- 页面受限时使用现有获准工具或请求用户提供正文/截图，不自动安装登录态提取工具、不索取或导出 Cookie。

输出来源、读取范围、核心内容、图片证据与未核验项。引用图片优先使用工具已提供的媒体；不为绕过展示限制下载远端图片。用户授权保存素材时按项目规则处理，不默认下载全部资源。

本公开版使用宿主读取能力，不包含旧 SSR 下载脚本、固定 Node 路径或共享临时目录；仅阅读不自动改笔记或素材队列。
